# FreeMermaid documentation

FreeMermaid is a browser-only Mermaid editor with a full diagram canvas and floating source panel. Your diagram source is rendered in the browser, saved in the browser, and downloaded from the browser.

## Choose a guide

- [Using the editor](using-the-editor.md) — use the floating editor and canvas, download, and reset a diagram.
- [Mermaid quick start](mermaid-quick-start.md) — start writing Mermaid with three common diagram types.
- [Privacy and offline](privacy-and-offline.md) — understand local persistence, caching, and what data FreeMermaid does not collect.
- [Development](development.md) — run the project, checks, and automated tests locally.
- [Deployment](deployment.md) — publish the static app through Cloudflare Pages.
- [Architecture](architecture.md) — understand rendering, exports, persistence, and PWA behavior.
- [Troubleshooting](troubleshooting.md) — resolve common usage and deployment issues.

For a compact overview, return to the [project README](../README.md).
